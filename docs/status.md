## Минимальные требования и звёздочки

Минимальные требования работают все 8. Звёздочки работают все 4:

Внешние системы (1С, банк, реестры) — имитации на тестовых данных.

## Чего нет и ограничения

- **Публичная ссылка не поднята.** Нужен VPS, развёртывание по [`deploy.md`](deploy.md), проверка — `scripts/smoke_test.sh https://<домен>`.
- **Общий WAPE по фактическому остатку немного хуже бейзлайна** «остаток не изменится», по медиане и по доле компаний — лучше. Финальный прогноз — смесь модели с бейзлайном (`core/reports/metrics.md`).
- **Настоящих подключений к 1С, банку и реестрам нет**, только имитации.
- **Выдержки из датасета.** В `docs/screens/` и `docs/demo_story.md` есть выдержки из датасета организаторов (компании и ИНН в нём вымышленные). Сам датасет (`data/raw/`) в git не входит.

## Что проверить вручную перед выступлением

1. Развернуть на VPS по `docs/deploy.md` и прогнать `bash scripts/smoke_test.sh https://<домен>`.
2. Открыть ссылку с телефона и нажать «Посмотреть демо».
3. Пройти `docs/demo_script.md` один раз с таймером: план — 3:50.
