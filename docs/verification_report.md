## 3. Что осталось

1. **Г2 / А3.** По общему WAPE на фактическом остатке прогноз немного хуже «остаток не изменится», по медиане и по доле компаний — лучше. Сжимать сильнее можно: на holdout WAPE 0,2585 против 0,2533, модель точнее у 69% компаний. Но тогда пропадают провалы перед зарплатой и налогами, и у C124 вероятность разрыва падает до 30%. Это решение команды.
2. **Г3.** Публичная HTTPS-ссылка — развёртывание на VPS по `docs/deploy.md` и `scripts/smoke_test.sh`.
3. **В1.** Настоящих подключений к 1С, банку и реестрам нет, только имитации на тестовых данных.
4. **Порог «вероятного» разрыва 50%.** На dev F1 лучше при пороге 40%: точность 61%, полнота 74%; на holdout — 54% и 80% против 70% и 61% при 50%. Порог не менялся, потому что он меняет смысл карточки риска. Это решение команды.
5. **Мелочь.** Линтер интерфейса выдаёт 3 предупреждения: `Date` в рендере и экспорт констант из `BalanceChart.tsx`. Ошибок нет.

